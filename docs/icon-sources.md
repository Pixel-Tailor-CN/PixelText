# 图标资源来源

## 短信通知小图标

以下资源为 Pixel Text 项目内重新绘制的 Android VectorDrawable，不包含从第三方图标库复制的路径数据：

- `ic_notification_sms.xml`：项目现有双气泡通知图标，同时作为默认选项与 Smartspacer 固定图标。
- `ic_sms_notification_single_bubble.xml`：依据项目旧版单气泡通知图标的语义重新绘制。
- `ic_sms_notification_envelope.xml`：项目内绘制的填充信封图标。
- `ic_sms_notification_text_bubble.xml`：项目内绘制的带文本镂空气泡图标。

iconfont 的短信搜索结果仅用于比较常见图标类别，没有下载、复制或转换第三方图标路径。
