# 验证码复制按钮窄屏适配设计

## 原问题

验证码聚合页曾使用至少 104dp 宽的文字复制按钮，与进入会话按钮争抢空间。2026-07 的修复为聚合页增加 `compactCopyButton` 可选模式，曾使用 48dp 图标按钮。

## 当前实现

后续卡片样式已统一，`VerificationCodeCard` 不再有 `compactCopyButton` 参数，也没有默认关闭的紧凑模式。聚合页和会话详情共用当前图标按钮：

- `FilledIconButton` 的显式布局尺寸为 40dp，图标为 20dp，保留“复制验证码”无障碍描述；实际触摸区域由 Material 组件最小交互约束处理。
- 验证码列使用 `weight(1f)`，与按钮间距为 12dp，内容区域横向内边距为 16dp。
- `VerificationCodeScreen` 传入 `showOriginal`／`originalLoading` 展开原文；不再传紧凑模式参数。
- 复制仍只写入剪贴板，不标记已读，不修改解析规则。

## 验证边界

原实施记录保留当时 Kotlin 编译与 Lint 完成状态；本次只核对当前源码，没有补做窄屏、字号或触摸验证。当前布局仍需在相关 UI 改动时检查验证码完整展示与复制可达性，不以固定按钮宽度保证任意长度、任意字号都能显示。项目不新增或运行单元测试。
