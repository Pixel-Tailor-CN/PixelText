# 验证码复制按钮窄屏适配设计

## 问题

验证码聚合页的每一项同时包含验证码卡片和“进入会话”按钮。验证码卡片内部还固定使用至少
104dp 宽的“复制”文字按钮、20dp 间距和 40dp 横向内边距。窄屏设备上，单行大字号验证码
因此只剩不足以显示 6 位字符的宽度，末位会被裁切。

## 方案

- 为 `VerificationCodeCard` 增加可选的紧凑复制按钮模式，默认关闭。
- 紧凑模式使用 48dp 圆形按钮和复制图标，并保留“复制验证码”无障碍描述。
- 紧凑模式下将验证码与按钮之间的间距从 20dp 缩小到 12dp。
- 只在验证码聚合页启用紧凑模式；会话详情页继续使用现有“复制”文字按钮。
- 不修改验证码字号、解析规则、卡片颜色和复制行为。

## 验证

- 执行 `./gradlew :app:compileDebugKotlin`。
- 执行 `./gradlew :app:lintDebug`。
- 在窄屏或验证码聚合页 Mock 场景中确认 6 位验证码完整显示，复制按钮仍可点击。
