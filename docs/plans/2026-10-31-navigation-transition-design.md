# 页面转场动画自定义设计

日期：2026-10-31。状态：设计完成，待实现。

需求来源：[GitHub Issue #24：支持自定义转场动画](https://github.com/Pixel-Tailor-CN/PixelText/issues/24)。用户已确定采用「默认、横向滑动、淡入淡出、无动画」四种预设，在「设置 → 显示与外观」选择，应用页面导航和设置分类切换共用配置，首页底部标签保持现有行为。本文补充可直接指导实现的交互、技术边界和验收要求；具体参数、弹窗形式和备份边界属于本设计的实现决策。

## 目标与范围

让用户选择适合自己的页面切换效果。首次安装和升级后未设置时保持现有视觉效果；选项即时保存并作用于后续导航，无需重启应用。

本次覆盖：

- 根 `AppNavigation` 中的页面前进、普通返回和已有预测性手势返回。
- `SettingsScreen` 中窄屏设置分类的进入、返回及跨分类跳转。
- 设置偏好的本机持久化和读取回退。

本次不覆盖首页「会话 / 验证码」平级标签切换、独立 Activity 的系统转场、弹窗和底部面板动效、短信列表条目动画、主题或其他组件动效。选项「无动画」仅关闭上述范围内的页面转场，不表示关闭全应用所有动画。暂不提供自定义时长、曲线、方向、逐页面配置、动画预览或新增动画库。

## 设置交互

在「显示与外观 → 应用与主界面」分组中，紧随「应用名称与图标」新增「页面转场动画」设置行，摘要为当前选项名称。继续使用现有 `Preference` 风格和 Material 3 颜色。

点击后打开标题为「页面转场动画」的单选弹窗，选项按以下顺序排列，每项含名称和简短说明：

| 名称 | 说明 |
| --- | --- |
| 默认 | 滑动、缩放与淡入淡出 |
| 横向滑动 | 左右滑动，返回时反向 |
| 淡入淡出 | 渐变切换，不移动页面 |
| 无动画 | 直接切换页面 |

弹窗增加范围说明「用于页面进入与返回，不影响底部标签和组件动画」。选中当前值；点击整行或单选按钮均立即保存并关闭弹窗，与现有时间格式设置一致。点击取消、弹窗外区域或系统返回只关闭弹窗，不更改设置。重复选择当前项不产生导航或其他副作用。

不为新选项新增专用路由。弹窗内容应可滚动，兼容大字号和横屏，单选行提供可访问的选择语义；装饰图标不重复朗读。浅色、暗色和动态取色沿用当前主题。

选择动作本身只更新设置，不重新播放当前页面的进入动画。关闭弹窗后，下次前进或返回即使用新效果，包括从「显示与外观」返回设置首页。宽屏下保持现有双栏布局和直接切换分类内容的行为，设置值仍影响根导航。

## 转场定义

新增 `ui/NavigationTransitions.kt`，集中提供按 `NavigationTransitionStyle` 选择的四个转场函数：前进进入、前进退出、返回进入、返回退出。根导航和设置分类只调用该公共实现，不分别维护动画参数。

枚举放在 `domain/settings/NavigationTransitionStyle.kt`，仅持有稳定存储值和解析逻辑，不依赖 Compose。界面显示名称和说明留在 UI 层。

| 枚举 | 存储值 | 默认行为 |
| --- | --- | --- |
| `DEFAULT` | `default` | 当前组合动画 |
| `SLIDE` | `slide` | 纯横向滑动 |
| `FADE` | `fade` | 纯淡入淡出 |
| `NONE` | `none` | 无页面转场 |

### 默认

把当前 `activityLike*Transition` 实现及相关常量移入统一转场文件，保持参数和组合方式：

- 前景页面全宽滑入或滑出，时长 300 ms。
- 背景页面移动四分之一宽度，时长 260 ms。
- 前景进入缩放从 0.96 到 1，返回退出缩放到 0.90；背景缩放值为 0.92。
- 进入淡入 90 ms；背景退出淡出延迟 120 ms、持续 90 ms；前景返回退出淡出延迟 210 ms、持续 90 ms。
- 滑动和缩放继续使用 `FastOutSlowInEasing`。

不在抽取过程中调整已有默认效果，旧调用点全部迁移后移除不再使用的导入和函数。

### 横向滑动

四个转场均使用 300 ms、`FastOutSlowInEasing`，不叠加缩放或透明度变化。

| 动作 | 进入页面 | 退出页面 |
| --- | --- | --- |
| 前进 | 从右侧一整页宽度滑至原位 | 从原位向左滑出一整页宽度 |
| 返回 | 从左侧一整页宽度滑至原位 | 从原位向右滑出一整页宽度 |

沿用当前导航的物理左右方向，不在本次增加 RTL 导航语义改造。

### 淡入淡出

前进和返回均使用 200 ms 的 `fadeIn` / `fadeOut`，显式使用 `LinearEasing`，不位移、不缩放。两个页面同时过渡，背景沿用宿主的 `MaterialTheme.colorScheme.background`。

### 无动画

四个转场分别返回 `EnterTransition.None` 或 `ExitTransition.None`。根导航的预测性返回回调同样显式返回对应的无动画转场，不使用 `null`，避免落回导航库默认效果。设置分类继续禁用尺寸动画，不因内容高度变化出现另一种转场。

## 状态与持久化

在 `AppSettings` 增加 `navigationTransitionStyle`，默认值由 `AppSettingsKeys.DEFAULT_NAVIGATION_TRANSITION_STYLE` 提供，值为 `DEFAULT`。存储键使用 `navigation_transition_style`，保存枚举的稳定字符串，不保存序号或显示名称。

在 `AppSettingsRepository` 增加 `setNavigationTransitionStyle` 和 `getNavigationTransitionStyle`，实现类在 `readSettings()` 中读取它，写入继续走现有 `updatePrefs`。`SettingsViewModel` 增加同名 setter 供界面调用。

不存在的键、空值或未知字符串统一解析为 `DEFAULT`。无需迁移现有偏好、清空设置或新增数据库表。未知值回退只影响有效读取结果，不在读取时反复写盘。

根 `AppNavigation` 通过已有 Koin 注册获取 `AppSettingsRepository` 并订阅其设置流；`SettingsScreen` 使用已有 ViewModel 的设置流。根导航不为读取一个偏好实例化完整的 `SettingsViewModel`，也不引入第二份设置源。仓库同步读取偏好形成初始 `StateFlow`，重启后的首次导航应直接使用已保存值。

设置变化只能更新转场选择，不能通过以风格为 `key` 的方式重建 `NavHost` 或 `NavController`，不能改变已有返回栈、当前分类和滚动状态。转场回调应读取当前有效风格，避免在无依赖的 `remember` 中捕获初始值。

## 返回与布局边界

根导航保持 `enterTransition`、`exitTransition`、`popEnterTransition`、`popExitTransition`、`predictivePopEnterTransition` 和 `predictivePopExitTransition` 六个回调。预测性返回的进入和退出使用所选风格的普通返回转场，由现有 Navigation 实现驱动手势进度、完成和取消，不新增自定义返回栈或手势进度控制。

`SettingsScreen` 保持 `navigatingBack` 的判断、前进 `targetContentZIndex = 1f`、返回 `targetContentZIndex = -1f` 以及 `.using(null)`。只替换所调用的转场函数，保持现有分类历史、跨分类返回和宽窄布局状态恢复逻辑。

设置分类当前使用普通 `BackHandler`，本次不改为 `PredictiveBackHandler`。因此分类返回在手势提交后执行所选动画，不承诺随手势进度预览；根导航已有的预测性返回则必须继续工作。验收时区分这两类返回，避免把设置分类现有能力误写为预测性返回。

设置更新发生在弹窗选择时，不主动中断或重启已在进行的转场。若设备验证发现手势进行期间外部状态变化会导致动画跳变，再在 UI 层增加仅针对活动转场的风格快照；不为尚未出现的问题新增全局状态机。

## 备份兼容性

本设计选择第一版仅将动画偏好保存在本机，不纳入 `BackupSettingsMapper.SPECS`，保持现有备份格式和校验逻辑。

理由：现有导入要求设置键集合与 `SPECS` 完全相同，直接加入字段会使旧备份被拒绝。为一个视觉偏好扩展备份迁移不属于本次范围。

预期结果：

- 应用升级保留本机已保存的动画选择。
- 在已有设置的设备上恢复备份，保持该设备原有动画选择，因为恢复只写入备份中包含的键。
- 新安装后恢复备份，没有本机偏好时使用默认动画。
- 导出内容不增加动画字段，既有备份校验行为不变。

后续若要求跨设备携带此选项，应独立设计可选字段或格式迁移规则，并覆盖旧备份兼容性，不直接扩充严格键集合。

## 验收与验证

按项目约定，不新增或运行单元测试。实现后先运行 `./gradlew.bat :app:compileDebugKotlin`；需要安装验证时运行 `./gradlew.bat :app:assembleDebug`，涉及静态规则或出现相关问题时补充 `:app:lintDebug`。检查差异，确认未修改首页标签动画、备份键列表或其他无关行为。

设备验证覆盖以下场景，并记录实际设备、Android 版本和未覆盖项：

| 场景 | 验收要求 |
| --- | --- |
| 首次安装或从旧版本升级 | 未配置时使用现有默认效果 |
| 选择四种预设 | 摘要、单选状态正确，选择后关闭弹窗，下一次导航生效 |
| 取消弹窗与重复选择 | 不意外修改偏好、触发导航或重播页面动画 |
| 退出进程再打开 | 保留选择，首次跳转就使用保存的效果 |
| 首页进入会话、设置进入专用页及返回 | 各风格符合定义；无动画模式不出现默认缩放或尺寸动画 |
| 设置首页进入显示分类再返回 | 前进、返回一致，切换偏好不丢失分类与滚动状态 |
| 消息分类跨到显示分类再返回 | 沿用原有返回目标与列表位置 |
| 根页面预测性手势返回完成与取消 | 每种风格均不闪屏、不遗留缩放/透明度状态、不重复弹栈；取消后仍在原页；无动画可直接呈现目标页面但取消必须正确恢复 |
| 设置分类手势返回 | 取消不导航，提交后使用所选转场；不要求进度预览 |
| 快速连续进出页面 | 不因风格读取或重组导致崩溃、错误页面或额外返回 |
| 首页底部标签、弹窗、列表动效 | 保持原有行为 |
| 深浅主题、动态取色、大字号和宽屏 | 内容可读可选，无水平溢出；宽屏仍为双栏 |
| 系统动画时长缩放为 0 | 不自建计时器绕开 Compose 的系统动画设置，导航正常完成 |
| 缺失或未知本机存储值 | 回退默认效果，不崩溃 |
| 旧备份恢复及本版导出再恢复 | 不因新偏好拒绝旧备份；当前设备的动画偏好保持不变 |

默认动画的视觉一致性、预测性返回的完成和取消必须通过设备观察确认，编译成功不能替代。无法使用设备时如实列为未验项。
