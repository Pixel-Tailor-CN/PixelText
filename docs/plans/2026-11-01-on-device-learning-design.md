# 全文识别与端侧二次学习：客户端设计

状态：全文识别与端侧个人学习已接入客户端；本文维护当前行为和设计约束，设备验证范围另行记录。样本贡献采用手动辅助脱敏，不再采用早期自动脱敏方案。

## 范围与公开边界

本仓库负责 Android 全文编码、本地推理与个人学习、数据管理、交互、资源兼容检查及确认后的样本贡献。设计、实施、评审和验证只在本仓库开展；外部依赖通过版本化公开协议和交付产物对接。

公开文档、注释和发布说明只描述客户端行为及必要协议，不包含资源生产流程、服务内部结构、训练工程信息、管理接口、私有仓库名称或本机路径。不链接私有文档，不要求开源贡献者取得私有源码才能理解客户端。

不包含 RCS、图片或附件学习、远程短信分类、自动上传；智能卡片规则保持不变。

## 已确认的用户行为

- 二次学习总开关默认关闭；贡献草稿保留原文及来源提供的发送方，历史学习记录不补造发送方，脱敏由用户手动编辑或主动应用辅助脱敏结果。
- 原手动骚扰标记位置替换为“让 AI 学习”，旧入口移除。新入口始终显示；关闭时引导开启并继续当前操作。如果 AI 识别也关闭，在同一引导中说明并由用户开启。
- 用户明确选择“骚扰短信”或“正常短信”，保存后立即发起本地学习，不承诺瞬时训练完成。
- 学习与上传独立：展示可编辑、待用户脱敏的贡献草稿，只有确认上传才发送。取消、断网、失败或审核结果不影响本地标签。
- 关闭开关保留样本和纠正，清除个人参数并停止个人训练及预测；重新开启后按现有样本重建，等待期间使用基础预测。
- 首次开启说明学习样本独立保存；删除原短信不会忘记学习，提供单条样本删除及清空入口。

## 判定与副作用

有效状态顺序：持久放行／白名单 → 关键词 → 当前消息人工纠正 → 有效个人预测 → 基础预测。个人模型替代基础 AI，不覆盖显式规则。冲突时说明学习已记录但规则仍生效，不伪称当前消息已改变分类。人工纠正仅关联明确操作的消息，不自动新增号码白名单。

统一判定在新短信、历史扫描、初始化扫描和详情识别等写入路径生成持久结果；骚扰列表、会话过滤、未读统计和 Smartspacer 读取镜像中的最终判定，不在读取时重新运行模型或校验正文指纹。当前阈值保持 0.7，调整须有独立证据。新短信沿用用户已有静默及自动处理设置；学习、迁移及历史重算不对历史消息已读、删除或补发通知。

最终系统副作用前复核规则及模型／样本／开关代次；过期结果重算或取消副作用，不能使用旧个人结果删除消息。

## 本地运行契约

采用共享基础能力与可学习个人分类层。基础参数不修改，个人参数独立保存并绑定模型和词表哈希；无学习记录时个人预测与基础预测应一致。

完整正文按 Unicode 码点编码，连续空白按版本化规则归一，不截取前 40 字。动态输入 `int32[1,N]`、`N>=1`；空正文不可学习。内存不足或拒绝超长输入时返回错误，不静默截断、不把失败当正常分数。保留词表索引：0 为 padding，第一行 `[UNK]` 对应 1。

公开接口为 `infer_public`、`infer_personal`、`train_personal` 和 `reset_personal`，个人参数通过显式张量传入、返回并独立持久化。客户端按 `model_contract.json` 验证输入输出名称、类型、形状及参数尺寸，不依赖内部网络层名。Java 运行库不执行零输入签名，因此重置仅接受经过校验的零算子、非变量常量子图，读取其初始参数；其他重置图明确拒绝。

只使用人工标签训练，不以模型预测生成标签。结合有效样本集更新，限制偏移；客户端校验版本化训练配置的合法性。任务串行合并，标签再次修改递增代次，旧任务不得覆盖新结果。训练与推理使用隔离的解释器／快照。

状态：排队、学习中、已生效、失败可重试。候选参数通过完整性和有限数值检查后，在独立学习库中按模型身份和样本代次事务提交。新增或修改标签的训练失败时保留旧参数；删除、清空及关闭立即撤销个人参数。需验证持久恢复、取消及进程死亡，不承诺一次学习即可正确泛化所有相似短信。

## 本地数据与生命周期

独立私有学习库保存 UUID、完整正文、人工标签、时间和样本代次；消息关联包含来源类型、来源 ID 和身份摘要。相同正文共享样本避免重复计权，冲突标签按最后操作更新，关联纠正同步变化；Provider ID 复用不能继承纠正。

预测记录保存基础版本、个人代次、来源和分数，人工纠正独立。旧分数 0/1 不推断为学习标签，旧缓存通过无副作用历史重算更新。

删除原短信移除消息关联和纠正，保留独立样本。删除学习样本撤销全部关联纠正并立即使旧参数失效，关联多条相同内容短信时在确认页显示影响数量，重建期间回到基础预测。清空删除样本、关联纠正和个人参数，不删除白名单或关键词。关闭开关通过 `invalidatePersonalParameters()` 清除参数并推进代次，保留样本以便重新开启后重建。

学习库和参数首版不加入手动备份、系统备份或设备迁移；卸载／清除数据会丢失学习成果。日志不含正文、原始发件信息或敏感特征。

## 样本贡献

复用现有手动脱敏助手、身份、请求幂等、未知结果恢复及“我的上报”。从短信详情进入时草稿保留正文与发送方；从历史学习记录进入时仅提供已保存的正文和最新标签，不补造未保存的发送方。用户可编辑或选择片段并应用辅助替换；不自动识别和替换敏感内容，不提供自动脱敏开关。辅助处理只修改上传草稿，不覆盖学习正文。

确认页展示最终正文、可选发件方和标签；上传编辑不回写本地标签。重试使用已确认的不可变负载和请求 ID，修改内容必须重新确认。取消不排队上传。本地可学习但不满足上报长度条件时明确仅本地生效，不裁剪正文绕过限制。

公开可选对象 `learningFeedback`：`origin="on_device_learning"`、`baseModelVersion`、`personalGeneration`、`originalLabel`。沿用必要身份和版本说明，不上传个人权重或样本库；审核结果不反向改变个人标签。

## 资源协议及升级

新客户端使用 `GET /api/v2/resources/manifest?appVersionCode=<当前版本>&modelContractVersion=2`。响应保留 rules/spamModel 结构，模型能力含 `minAppVersionCode`、`modelContractVersion`、`preprocessingVersion`、`personalParameterVersion`、`featureCompatibilityId`，模型／词表各含哈希、大小和地址。这只是客户端消费协议，不描述服务内部实现。

版本 2 是当前全文及个人学习契约；详细张量由 `ModelContract` 和内置 `model_contract.json` 校验。检查、下载和激活都拒绝过高最低版本或未知契约；协议不可用或无兼容资源时保留本机可用资源，不降级加载不兼容旧模型。

新版内置全文模型和匹配词表，首次升级不将旧下载模型作为新契约主模型。模型、词表、个人参数形成完整组合。

学习开启且有样本时，在候选资源上重建个人参数，完成后原子激活；此前继续使用旧组合。失败显示更新未完成；无样本或开关关闭可直接启用新基础资源，旧个人参数失效，重新开启时重建。关闭、删除、升级和训练完成共用代次校验；崩溃恢复最后完整组合。

## 验收与独立交付

本仓库执行 Kotlin 编译、Lint、必要 APK 构建及合成消息／Mock／真机检查，不新增或运行单元测试。覆盖长文本尾部、Unicode、规则冲突、样本改删、关闭期间升级、训练与收信并发、上传取消和恢复、备份排除。

测量推理／学习时延、内存和包体；质量及性能目标在样件基线后确定，未验真机不可宣称通过。独立交付客户端变更、协议兼容证据及未验项；不操作外部部署或自动发布 App，版本号沿用 Git 历史生成。
