# 底部导航未读消息徽标设计

## 目标

在首页底部导航栏的“会话”按钮上显示未读消息总数，并在设置页面提供默认开启的“未读红点提醒”开关。

## 展示规则

- 未读总数为 `0` 时不显示徽标。
- 未读总数为 `1–99` 时显示具体数字。
- 未读总数大于 `99` 时显示 `99+`。
- 徽标使用 Material 3 `Badge`，采用主题的 `error` 与 `onError` 配色，以适配动态取色和深色模式。
- 徽标仅附着在“会话”导航图标上，不修改“验证码”导航按钮。

## 未读统计

- 统计口径为符合条件的未读 SMS 总条数，不是未读会话数量。
- 不统计 MMS。
- 直接读取系统 SMS ContentProvider 中 `READ = 0` 的收件箱短信，与 Smartspacer 使用相同的数据源。
- 始终排除已归档会话中的短信。
- “隐藏完全骚扰对话”开启时，排除完全骚扰会话中的未读短信；关闭时计入。
- App 与 Smartspacer 共用一个底层未读 SMS 计数器，Smartspacer 继续按自身的普通、骚扰、归档配置传入过滤条件。
- 不新增数据库字段或迁移。

## 设置

- `unreadBadgeEnabled` 默认值为 `true`。
- 设置持久化继续使用 `AppSettingsRepository` 和现有 SharedPreferences。
- 设置页“应用功能”分类增加“未读红点提醒”开关。
- 关闭开关后立即隐藏徽标，但继续维护未读数量，不改变会话列表的未读样式和短信读状态。

## 组件与数据流

1. 共享未读 SMS 计数器读取系统未读 SMS，并结合归档和骚扰数据执行分类过滤。
2. Smartspacer 使用共享计数器并传入自身的普通、骚扰、归档开关。
3. 首页状态层监听 SMS ContentProvider、归档数据、骚扰识别结果和 App 设置变化，任一变化都会重新计数。
4. `HomeScreen` 订阅未读总数及“未读红点提醒”设置。
5. “会话”图标根据开关和未读总数决定是否使用 `BadgedBox` 展示徽标。

## 异常处理

- 系统短信查询失败时保留最近一次成功结果，并记录不包含短信正文的英文日志。
- 负值防御性约束为 `0`。
- 未读数变化只影响徽标渲染，不阻塞底部导航交互。

## 验证

- 编译 Debug Kotlin。
- 运行 Android Lint。
- 模拟器验证默认开启、关闭即时隐藏、重新开启恢复。
- 模拟器验证 `0`、普通数量和 `99+` 三种展示规则。
- 验证标记已读和通知快捷回复后的徽标数量能够刷新。
- 验证归档短信始终不计数，“隐藏完全骚扰对话”能够控制完全骚扰会话是否计数。
- 验证 MMS 不计入数量。

项目约定不新增单元测试或 Android 仪器测试。
